## 📌 PROJECT OVERVIEW

**Sefalana Retail Website** is a complete, fully-functional multi-page retail business website built with HTML, CSS, and JavaScript. It simulates a real-world retail operation with customer-facing features, B2B supplier management, and an administrative dashboard.

### Purpose
This website serves as a digital storefront for Sefalana, showcasing:
- Weekly specials and promotions
- Store locations across Botswana
- B2B supplier registration
- Administrative management tools
- Shopping cart functionality

### Target Audience
- **Customers** - Browse specials, find stores, shop
- **Suppliers** - Register as business partners
- **Administrators** - Manage content and inquiries

---

## ✨ FEATURES

### 🏠 Home Page
- Hero banner with brand messaging
- Preview of weekly specials (3 items)
- Preview of store locations (3 stores)
- Quick navigation to all sections
- Stats bar (Years, Stores, Products, Customers)
- Responsive design for all devices

### 🛒 Weekly Specials Page
- Complete list of all special offers (6+ items)
- **Filter system**:
  - All Specials
  - Featured Items
  - Food & Beverages
  - Household
- Price display (original vs. special)
- Savings percentage badge
- Add to Cart functionality
- Image hover zoom effect

### 📍 Store Locator Page
- Complete list of all store locations
- **Search functionality**:
  - Text search (name or address)
  - City filter dropdown
  - Store format filter (Hyper, Shopper, Cash & Carry)
- Store details (address, phone, hours)
- Interactive "View Details" buttons
- **Special background pattern** showing "YEARS of creating value"

### 🤝 B2B Supplier Page
- Supplier inquiry form with validation
- Required fields: Company, Contact Person, Email, Phone, Message
- Optional fields: Business Type, Revenue Range
- Form validation (email format, phone length)
- Success message with auto-hide
- Data logging (console) for demonstration

### 🔐 Admin Portal
- Secure login system
- **Dashboard metrics**:
  - Total Stores
  - Active Specials
  - Pending Inquiries
  - Monthly Revenue
- **Inquiry Management**:
  - View all pending inquiries
  - Mark as "Contacted"
  - Archive inquiries
  - Real-time status updates
- Logout functionality

### 🛍️ Shopping Cart
- Display cart items with images
- Quantity adjustment (+ / - buttons)
- Individual item removal
- Running total calculation
- Clear cart (with confirmation)
- Checkout (demo functionality)
- Empty cart state with shopping link
